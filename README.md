# A Cosmology-Independent Test of Type Ia Supernova Luminosity Evolution

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)

This repository contains the official data and Python source code for the paper:  
**"A Cosmology-Independent Test of Type Ia Supernova Luminosity Evolution using Compact Radio Sources and MILP Global Optimization"** (Hu et al. 2026, submitted to *The Astrophysical Journal*).

## Overview

This project provides a robust, purely kinematic framework to test for redshift-dependent luminosity evolution in Type Ia supernovae (SNe Ia) without relying on the early-universe sound horizon ($r_d$) or assuming a specific cosmological expansion model (e.g., $\Lambda$CDM). 

We bridge the Pantheon+ SN Ia compilation with high-redshift Compact Radio Sources (CRS) via the Cosmic Distance-Duality Relation (CDDR). To eliminate heuristic pairing biases, we introduce **CosmoMatcher**, a Mixed-Integer Linear Programming (MILP) algorithm designed to extract systematically optimized cross-probe pairs.

## Repository Contents

* **`CosmoMatcher_v1.1.py`**: The MILP-based global optimization tool used to cross-match discrete standard candles and standard rulers based on comoving-distance tolerances.
* **`run_mcmc_evolution.py`** *(formerly mcmc_sn_evolutionv5m.py)*: The core Markov Chain Monte Carlo (MCMC) script. It executes the four complementary test modes (linear evolution, log evolution, pure CDDR violation, and joint analysis) discussed in the paper.
* **`cosmo_tools.py`**: Auxiliary functions for calculating posterior statistics and generating `getdist` triangle plots.
* **`check_delta_z.py`**: A lightweight script to quantify the residual redshift mismatch ($|\Delta z|$) between the matched pairs.
* **`ucsdata.CSV`**: The catalog of 120 Compact Radio Sources (CRS) calibrated by Cao et al. (2017).
* **`matched_cluster_milp_dd_pantheon.csv`**: The globally optimized 48 CRS-SN Ia pairs generated by CosmoMatcher.
* **`cov_cluster_milp_dd_pantheon_lens.txt`**: The corresponding $48 \times 48$ statistical+systematic covariance sub-matrix extracted from the Pantheon+ release.
